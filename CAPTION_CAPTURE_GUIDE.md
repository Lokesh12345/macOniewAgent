# Caption/Subtitle Capture Guide

## Overview

The Universal Video Handler provides comprehensive caption/subtitle support across all major video platforms. This document explains what's possible, platform limitations, and when video playback is required.

## ⚡ Quick Summary

**Can capture captions WITHOUT playing video:**
- ✅ **HTML5 videos** - Full caption list and metadata
- ✅ **Vimeo** - Complete caption track information  
- ⚠️ **YouTube** - Limited detection (depends on page data)
- ❌ **Netflix/Prime** - Usually requires playback

**Can extract caption TEXT (even without playing):**
- ✅ **HTML5 videos** - Complete caption extraction with timestamps
- ❌ **YouTube** - Not accessible via API
- ❌ **Vimeo** - Not accessible via API  
- ❌ **Netflix/Prime** - Not accessible via API

**Can extract caption TEXT during playback:**
- ✅ **HTML5 videos** - Real-time caption text with timestamps
- ❌ **YouTube** - Not accessible via API
- ❌ **Vimeo** - Not accessible via API  
- ❌ **Netflix/Prime** - Not accessible via API

## Platform-Specific Capabilities

### 🎬 HTML5 Video (Best Support)

**What works WITHOUT playback:**
```javascript
// Get all caption tracks
{ action: "getCaptions" }
// Returns: List of all available tracks with language, kind, label

// Enable specific caption
{ action: "enableCaption", time: "en" }
// Returns: Success confirmation

// Check current settings
{ action: "disableCaptions" }
// Returns: All tracks disabled
```

**What works DURING playback:**
```javascript
// Get current caption text with timing (during playback)
{ action: "getCurrentCaption" }
// Returns: {
//   "text": "Hello, this is the current caption text",
//   "startTime": 125.5,
//   "endTime": 128.0,
//   "language": "en"
// }

// Extract ALL caption text (works WITHOUT playback!)
{ action: "extractAllCaptions" }
// Returns: Complete transcript with timestamps

// Get caption text at specific time
{ action: "getCaptionText", time: "125.5" }
// Returns: Caption text at that specific timestamp
```

**Example Response:**
```json

  "success": true,
  "playerType": "html5",
  "captions": [
    {
```

### 🔴 YouTube (Limited Support)

**What works WITHOUT playback (sometimes):**
- Caption detection via `ytInitialPlayerResponse` if available
- Language list extraction from page metadata
- Auto-generated vs manual caption identification

**Limitations:**
- YouTube API restricts direct caption access
- Caption text content is NOT accessible
- May require video to start for better detection
- Uses DOM manipulation for enable/disable

**Example Response:**
```json
{
  "success": true,
  "playerType": "youtube",
  "captions": [
    {
      "kind": "subtitles",
      "language": "en",
      "label": "English",
      "isDefault": false,
      "isAutoGenerated": true
    }
  ],
  "message": "Found 1 caption tracks",
  "limitation": "YouTube caption access is limited. Start video playback for better detection."
}
```

### 🎵 Vimeo (Good API Support)

**What works WITHOUT playback:**
- Complete caption track enumeration via `getTextTracks()`
- Language, label, and kind information
- Enable/disable via official API

**What doesn't work:**
- Caption text content is not exposed by API
- VTT file URLs use expiration tokens

**Example Response:**
```json

  "captions": [
    {
      "kind": "subtitles",

      "kind": "captions",
      "language": "fr", 
      "label": "Français",

      "isActive": false
    }
  ],
  "message": "Found 2 caption tracks"
}
```

### 📺 Netflix/Prime (Minimal Support)

**Limitations:**
- Platform actively blocks caption access
- Internal APIs frequently change
- Usually requires video playback for any detection
- DOM manipulation only, unreliable

## Usage Patterns

### 1. Caption Discovery (No Playback Required)

```javascript
// Check what captions are available
const result = await performVideoAction('getCaptions');

if (result.success && result.captions.length > 0) {
  console.log('Available captions:');
  result.captions.forEach(caption => {
    console.log(`- ${caption.label} (${caption.language})`);
  });
} else {
  console.log('No captions available');
}
```

### 2. Caption Control (No Playback Required)

```javascript
// Enable Spanish subtitles
await performVideoAction('enableCaption', 'es');

// Disable all captions
await performVideoAction('disableCaptions');
```

### 3. Full Caption Extraction (No Playback Required!)

```javascript
// Extract ALL captions from HTML5 video without playing
const allCaptions = await performVideoAction('extractAllCaptions');

if (allCaptions.success) {
  console.log(`Found ${allCaptions.totalTracks} tracks with ${allCaptions.totalCues} total captions`);
  
  allCaptions.tracks.forEach(track => {
    console.log(`\n${track.label} (${track.language}):`);
    track.cues.forEach(cue => {
      console.log(`[${cue.startTime}s-${cue.endTime}s] ${cue.text}`);
    });
  });
}
```

### 4. Caption Text at Specific Time

```javascript
// Get caption text at specific timestamp (no playback required)
const captionAt125s = await performVideoAction('getCaptionText', '125.5');

if (captionAt125s.success && captionAt125s.results.length > 0) {
  captionAt125s.results.forEach(result => {
    console.log(`${result.label}: "${result.text}"`);
  });
}
```

### 5. Real-time Caption Extraction (During Playback)

```javascript
// Get current caption during playback
const captionResult = await performVideoAction('getCurrentCaption');

if (captionResult.success && captionResult.text) {
  console.log(`Current: "${captionResult.text}"`);
  console.log(`Timing: ${captionResult.startTime}s - ${captionResult.endTime}s`);
} else {
  console.log('No caption text at current time');
}
```

## Agent Implementation Examples

### Basic Caption Check
```javascript
// Agent workflow: Check and enable captions
async function setupCaptions(preferredLanguage = 'en') {
  // 1. Get available captions (works without playback)
  const captions = await performVideoAction('getCaptions');
  
  if (!captions.success) {
    return { error: 'No captions available on this video' };
  }
  
  // 2. Find preferred language
  const targetCaption = captions.captions.find(c => 
    c.language === preferredLanguage || 
    c.label.toLowerCase().includes(preferredLanguage)
  );
  
  if (targetCaption) {
    // 3. Enable the caption
    const result = await performVideoAction('enableCaption', preferredLanguage);
    return { success: true, enabled: targetCaption.label };
  } else {
    return { 
      error: `${preferredLanguage} captions not available`,
      available: captions.captions.map(c => c.language)
    };
  }
}
```

### Full Transcript Extraction (HTML5 Only)
```javascript
// Extract complete video transcript without playing (HTML5 only)
async function getFullTranscript() {
  const result = await performVideoAction('extractAllCaptions');
  
  if (result.success) {
    // Create a complete transcript
    const transcript = [];
    
    result.tracks.forEach(track => {
      if (track.language === 'en') { // Focus on English
        track.cues.forEach(cue => {
          transcript.push({
            time: cue.startTime,
            text: cue.text
          });
        });
      }
    });
    
    // Sort by time
    transcript.sort((a, b) => a.time - b.time);
    
    // Output formatted transcript
    transcript.forEach(entry => {
      const minutes = Math.floor(entry.time / 60);
      const seconds = Math.floor(entry.time % 60);
      console.log(`[${minutes}:${seconds.toString().padStart(2, '0')}] ${entry.text}`);
    });
    
    return transcript;
  }
  
  return null;
}
```

### Caption Search and Lookup
```javascript
// Search for specific text in captions (HTML5 only)
async function searchCaptions(searchText) {
  const allCaptions = await performVideoAction('extractAllCaptions');
  
  if (!allCaptions.success) return [];
  
  const matches = [];
  
  allCaptions.tracks.forEach(track => {
    track.cues.forEach(cue => {
      if (cue.text.toLowerCase().includes(searchText.toLowerCase())) {
        matches.push({
          language: track.language,
          startTime: cue.startTime,
          endTime: cue.endTime,
          text: cue.text,
          matchedTerm: searchText
        });
      }
    });
  });
  
  return matches;
}

// Get caption at exact timestamp
async function getCaptionAtTime(seconds) {
  const result = await performVideoAction('getCaptionText', seconds.toString());
  
  if (result.success && result.results.length > 0) {
    return result.results[0].text;
  }
  
  return null;
}
```

### Caption Text Monitoring (HTML5 Only)
```javascript
// Monitor captions during playback (HTML5 only)
async function monitorCaptions() {
  const interval = setInterval(async () => {
    const caption = await performVideoAction('getCurrentCaption');
    
    if (caption.success && caption.text) {
      console.log(`[${caption.startTime}s] ${caption.text}`);
    }
  }, 1000); // Check every second
  
  // Stop monitoring after 60 seconds
  setTimeout(() => clearInterval(interval), 60000);
}
```

## Technical Limitations by Platform

### YouTube Restrictions
- **API Limitation**: Google restricts caption access to video owners only
- **Detection**: Relies on `ytInitialPlayerResponse` which may not always be available
- **Text Access**: Caption content is never accessible via JavaScript
- **Workaround**: DOM manipulation of player controls (unreliable)

### Vimeo Limitations  
- **API Available**: Good track detection and control
- **Text Access**: VTT files use expiration tokens, not directly accessible
- **Reliability**: Most reliable for enable/disable operations

### HTML5 Advantages
- **Standard API**: Uses W3C TextTrack standard
- **Full Access**: Complete caption metadata and text content
- **Reliability**: Works consistently across browsers
- **Real-time**: Can extract current caption text during playback

### Streaming Platform Restrictions
- **DRM Protection**: Netflix, Prime actively block caption access
- **API Changes**: Internal APIs change frequently
- **Detection**: Usually requires video to be playing

## Best Practices

### 1. Graceful Degradation
```javascript
async function handleCaptions(action, language) {
  try {
    const result = await performVideoAction(action, language);
    
    if (!result.success) {
      console.log(`Caption ${action} failed: ${result.error}`);
      
      // Provide fallback suggestions
      if (action === 'getCaptions' && result.limitation) {
        console.log('Suggestion: Start video playback for better detection');
      }
    }
    
    return result;
  } catch (error) {
    console.log(`Caption operation failed: ${error.message}`);
    return { success: false, error: error.message };
  }
}
```

### 2. Platform Detection
```javascript
async function getCaptionsWithContext() {
  const captions = await performVideoAction('getCaptions');
  
  if (captions.success) {
    console.log(`Platform: ${captions.playerType}`);
    
    switch (captions.playerType) {
      case 'html5':
        console.log('✅ Full caption support available');
        break;
      case 'vimeo':
        console.log('✅ Good caption control, no text extraction');
        break;
      case 'youtube':
        console.log('⚠️ Limited caption access');
        break;
      default:
        console.log('⚠️ Basic caption support');
    }
  }
  
  return captions;
}
```

### 3. Error Handling
```javascript
const CAPTION_ERRORS = {
  'No captions available': 'Video does not have subtitle tracks',
  'Caption track not found': 'Requested language not available',
  'Caption text not accessible': 'Platform does not allow text extraction',
  'YouTube caption access is limited': 'Try starting video playback first'
};

function handleCaptionError(error) {
  const suggestion = CAPTION_ERRORS[error] || 'Unknown caption error';
  console.log(`Caption Error: ${suggestion}`);
}
```
